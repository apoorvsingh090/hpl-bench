# HPL-Bench — LLM-judge rubric (Hindi)

`saar` / `lekhan` / `grounded-long` का आधिकारिक स्कोर LLM-judge + मानव-ऑडिट से तय होता है।
`src/evaluate.py` का token-F1 केवल सूचनात्मक है।

## Judge settings (v0.1.1, seed)

* Judge model: कोई भी प्रबल बहुभाषी मॉडल (उदा. GPT-4o / Gemma-3-27b-it / Sarvam-M)।
  पेपर/लीडरबोर्ड में judge का नाम + version + temperature अवश्य लिखें।
* Decoding: `temperature=0.0`, अधिकतम 512 टोकन, JSON-only output।
* Calibration: प्रत्येक ट्रैक पर 20 मानव-स्कोर्ड नमूनों से Cohen-kappa ≥ 0.6 लक्ष्य;
  5% मानव-ऑडिट अनिवार्य (C1/lekhan में 10% सुझावित)।

## Scoring (प्रत्येक 1-5)

* **शुद्धता** — व्याकरण, वर्तनी, मात्रा, परसर्ग शुद्ध।
* **स्पष्टता** — विचार/तथ्य स्पष्ट, विषय पर केंद्रित, कोई हैलुसिनेशन नहीं।
* **संगठन** — अनुच्छेद-क्रम, प्रवाह, प्रारूप (पत्र/सूचना/संवाद हेतु)।
* **उपयुक्तता** — शब्द-सीमा, उद्देश्य, रजिस्टर (औपचारिक/अनौपचारिक/Hinglish) के अनुरूप।

## Judge prompt (copy-paste)

```
आप HPL-Bench के निष्पक्ष परीक्षक हैं। केवल JSON में स्कोर दें।
कार्य: {track} | स्तर: {level}
निर्देश: {prompt_hi}
गद्यांश/अंश: {passage_hi}
मॉडल उत्तर: {prediction}
संदर्भ उत्तर (यदि हो): {answer}
रब्रिक: शुद्धता, स्पष्टता, संगठन, उपयुक्तता — प्रत्येक 1-5।
दंड: तथ्य बदलने/नई जानकारी जोड़ने पर स्पष्टता ≤2; उद्धरणहीन grounded उत्तर पर उपयुक्तता ≤2;
शब्द-सीमा उल्लंघन पर उपयुक्तता -1।
JSON: {"shuddhata": 1-5, "spashtata": 1-5, "sangathan": 1-5, "upyuktata": 1-5, "tippani": "एक वाक्य"}
```

## Bias controls

* Verbosity: लंबाई को स्वतः गुण न मानें; संक्षिप्त-सही > लंबा-भटका।
* Self-preference: judge अपना मॉडल-परिवार न जाने; blind ID से स्कोर करें।
* Dialect/register: तत्सम/उर्दू-निष्ठ/Hinglish को विषय-उपयुक्तता से जाँचें, निजी झुकाव से नहीं।
* Position: pairwise तुलना में क्रम बदलकर दोहराएँ।
